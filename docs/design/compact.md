# 夜色小城速查

| 角色 | 来源与规则 |
| :--- | :--- |
| 背景 | `--bg`、`--bg-1`、`--bg-2`，原手册夜色 |
| 文字 | `--text`、`--text-2`、`--text-3`，原手册暖纸 |
| 操作 | `--grad-warm`，暖金到珊瑚 |
| 状态 | `--safe`、`--warn`、`--danger`、`--info` 与文字标签 |
| 字体 | `--font-display`、`--font-latin`、`--font-sans`、`--font-mono` |
| 圆角与缓动 | 原手册 `--r-*`、`--ease-out`、`--t-*` |
| 图解 | 复用原 mascot，灯带与光门只作示意 |

页面共享原始 token 文件和 mascot 实现，禁止复写成第二套独立配色或引入外部字体。
