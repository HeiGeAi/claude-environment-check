# 隐私与检测边界

## 公开仓库与个人报告

公开仓库不收录开发者或用户的真实个人体检报告、机器快照、短期认证状态、实际代理端口与本机验收截图。文档介绍能力与已执行的测试类别，测试夹具使用合成数据；项目不依赖开发者当前机器环境。

检测时生成的报告由用户保存在自己的目录，由用户掌握和决定是否删除或分享。即使已脱敏，环境摘要也可能暴露使用习惯。反馈问题时建议提供最小描述与合成复现步骤，不附带完整个人报告。

## 网页

进入首页仅加载本站静态资源。不自动运行探针，不请求账号、不上传报告，无统计埋点。

点击开始检测会读取当前浏览器提供的基础能力，并发起固定的公开 HTTPS 请求：

| 目的地 | 目的 | 共享的数据 |
| :--- | :--- | :--- |
| api.ipify.org | IPv4 出口观察 | 出口 IP、请求元数据 |
| api6.ipify.org | IPv6 出口观察 | 出口 IP、请求元数据 |
| www.cloudflare.com/cdn-cgi/trace | 当前路径出口、接入地区及连接信息 | 出口 IP、请求元数据 |
| stun.cloudflare.com:3478（可选） | 收集当前浏览器暴露的 ICE 候选 | 网络地址与 STUN 请求元数据 |

HTTPS 请求使用 `credentials: omit`，不会携带本站或 Claude Cookie。STUN 仅在明确勾选后启动，超时后关闭连接。探针供应商有自己的服务政策与可用性限制。

原始地址仅暂存于当前网页运行内存，用于地址族识别和同族比较。导出用随机别名保留相等关系，避免传播原始 IP 或可枚举的 IP 哈希。地址显示、日志和截图仍需本人审查。

导入 JSON 通过浏览器 File API 本地读取，只接受受限结构并作为文本呈现。本站没有上传接口。导入内容是历史报告，不能代表导入时的实时环境。

浏览器无法完整读取系统 DNS、路由、防火墙、后台客户端、CLI 认证与代理配置。没有 WebRTC 候选不代表没有泄漏；请求因 CORS、超时或 IPv6 不可达失败时标为未知。

## 本地检测器

默认不执行本工具网络探针，只读取定向系统信息，执行查询命令与 CLI 认证状态读取。认证查询使用受控干净环境，不加载用户 shell 启动脚本，也不会替用户登录。已安装官方 CLI 是独立程序，本工具没有为它建立网络隔离，因此不承诺查询过程绝对没有任何网络行为。

主动联网和 doctor 为独立选项。doctor 可能进行网络查询；联网探针仅访问代码中固定的公开目的地，不读取模型密钥，不关闭 TLS，不因代理失败切换到 DIRECT。

导出不包含凭据、账户邮箱、用户名、机器名、原始 IP、订阅地址、完整环境变量、完整配置和会话历史。输出目录及文件使用私有权限，完成后原子写入。报告仍包含版本、时区、运行范围等环境摘要，分享前请本人复查。

## 结论适用范围

每个结果对应一次观察时间和一个执行入口。网页、Desktop 与 CLI 分别对待。权限不足或未做故障演练必须保留 UNKNOWN／SKIPPED。

地区推断、同族探针结果一致和 TLS 可达不能保证账户资格、账号处置或整机断线保护。本项目不计算封号概率、不提供安全认证。
