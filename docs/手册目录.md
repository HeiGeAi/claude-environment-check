# 完整手册目录

[打开手册](https://heigeai.github.io/claude-environment-check/) 后，可从顶部进入辅助环境检测。手册包含小白与进阶两种阅读模式，章节动画用于解释原理，检测结果另行标注证据范围。

| 章节 | 内容 |
| :--- | :--- |
| [封面](https://heigeai.github.io/claude-environment-check/#hero) | 完整手册封面 |
| [先说实话](https://heigeai.github.io/claude-environment-check/#truth) | 这份指南能做什么、不能做什么 |
| [10 个词](https://heigeai.github.io/claude-environment-check/#words) | 用生活比喻认识关键术语 |
| [请求的旅程](https://heigeai.github.io/claude-environment-check/#journey) | 动画看懂一次请求怎样安全出门 |
| [两种接入方式](https://heigeai.github.io/claude-environment-check/#modes) | 围墙和告示牌，各有什么坑 |
| [四道防线](https://heigeai.github.io/claude-environment-check/#layers) | 从收拢流量到防止自己拆墙 |
| [域名与进程](https://heigeai.github.io/claude-environment-check/#domains) | 只记 claude.ai 远远不够 |
| [IP 与指纹](https://heigeai.github.io/claude-environment-check/#fingerprint) | 三件事，分开看 |
| [读懂检测报告](https://heigeai.github.io/claude-environment-check/#report) | 第三方历史截图，逐项解释 |
| [动手搭建](https://heigeai.github.io/claude-environment-check/#build) | 八步施工图与配置模板 |
| [门禁](https://heigeai.github.io/claude-environment-check/#gatekeeper) | 别让 AI 助手拆了防线 |
| [失败演练](https://heigeai.github.io/claude-environment-check/#drill) | 断线时也不能偷偷直连 |
| [排障与恢复](https://heigeai.github.io/claude-environment-check/#fix) | 先止损，再判断 |
| [隐私与遥测](https://heigeai.github.io/claude-environment-check/#privacy) | 四个开关，各管各的 |

| [万一被限制](https://heigeai.github.io/claude-environment-check/#appeal) | 申诉时只讲事实 |
| [24 项清单](https://heigeai.github.io/claude-environment-check/#checklist) | 勾完一遍，心里有数 |
| [来源与边界](https://heigeai.github.io/claude-environment-check/#sources) | 方法可复核，隐私留本地 |

所有章节源码、样式、图解、字体和交互代码均在仓库 `manual/` 中。构建后手册位于网站根目录，辅助检测位于 `check/`。下载静态包后用本地 HTTP 服务阅读，复制代码前替换占位符并核对适用条件。
