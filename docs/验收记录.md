# 验收类别与兼容范围

本记录说明实际执行过的测试类别、覆盖范围与尚未验证的能力，不公开开发者的机器快照、短期环境状态或真实个人报告。具体测试证据由维护者私下保留，公开测试夹具使用合成数据。

## macOS 本地核心

已在真实 macOS 环境执行只读检查。未修改账户、路由、代理、防火墙或常驻服务。

| 实际执行的类别 | 验证范围 |
| :--- | :--- |
| 默认本机检查 | 默认没有执行工具网络探针；安装、认证查询与宿主变量采集按白名单输出 |
| 显式本地 HTTP 代理 | 使用明确选择的路径发起匿名 HTTPS 探针；识别地址族并在单份报告内比较别名 |
| 当前系统 curl 路径 | 采集当前 curl 请求可观察的结果，不外推为全部应用路径 |
| 无效本地 HTTP 代理端口 | 所选路径失败时不直连重试，一致性证据不足保留 UNKNOWN |
| 官方 doctor | 检查告警解析，成功退出不覆盖已识别的诊断线索 |
| 非管理员 PF 查询 | 权限不足保留 UNKNOWN，不判断 PF 不存在 |
| 报告保存及读回 | 私有目录与文件权限、有效 JSON、ISO 时间和原始地址脱敏 |
| skill 解压至新位置运行 | 指令与脚本一起搬迁后仍可执行并生成新的报告 |

## 语义与合成测试

22 项 Python 测试通过，包含认证状态格式、doctor 告警、双栈判定、失败路径、代理限制、凭据脱敏、时间保护、子进程上限、私有报告与中断结果。

网页报告测试覆盖 schema、聚合、地址族、长度与深度限制、原型字段拒绝、凭据脱敏与时间保护。恶意 HTML 文本、秘密字符串与畸形 JSON 采用合成样本，在实际浏览器中验证文本渲染和导出处理。

测试中的版本号、端口与固定日期是合成夹具。网络判定用例使用预设的响应数据，不向其中的地址发请求。这些用例验证程序逻辑，不能替代真实网络或整机故障演练。

依赖审计、源代码确定性扫描与发布前检查已执行。此记录不把某次审计结果作为未来依赖版本的永久安全保证。

## 仍未验证

Windows／Linux 系统采集、真实手机、Safari／Edge、更多代理客户端、Shadowrocket 私有配置、用户日常浏览器策略、整机断线阻断、DNS 泄漏、账户额度及真实模型调用仍未验收。

Python 3.10 为最低语法要求。CI 对声明版本运行逻辑测试及构建；Linux 上的 CI 不能构成 Linux 系统采集支持。

同一本机 Agent 产品中的两个独立 Agent 已分别调用同一核心并复核范围。不同 Agent 产品的独立使用与多机器试用尚未完成。使用时应保留上述缺口，提供最小问题描述与合成复现步骤，避免公开个人机器报告。
