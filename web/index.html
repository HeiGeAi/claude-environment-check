配合手册核对当前浏览器的网络信息。每项结果注明检测范围，方便您回到相关章节继续排查。

无需登录。报告在浏览器本地处理。运行前可查看下面的测试范围与第三方服务。

01 / BROWSER CHECK

检测当前浏览器

这一轮只检查此浏览器能观察到的信息。网页无法读取本机 Claude 登录、代理规则、DNS 路径与系统防火墙。

测试范围与访问目的

IPv4 出口
api.ipify.org返回浏览器请求的 IPv4 地址。
IPv6 出口
api6.ipify.org尝试返回 IPv6 地址。失败保留为未验证。
当前连接
www.cloudflare.com/cdn-cgi/trace读取当前请求的 IP、地区代码和连接信息。

请求不携带登录凭据，每项最多等待 8 秒。服务方会看到您的请求与出口 IP，可能按其政策记录。页面不会替您登录 Claude，也不会绕过浏览器的访问限制。

时区、语言与在线状态只用于说明当前上下文，不生成指纹标识，不评估封号概率。

    LOCAL / AGENT SKILL

    让 Agent 检查本机

    本机工具进一步检查安装、CLI 登录状态、启动环境、代理与路由。它输出可核对的 JSON 和中文报告。

    把开源项目中的 Skill 交给具有本地终端权限的 Agent，先运行只读检查。网络探测需要单独启用。云端 Agent 检查的是它所在的机器。

    查看安装与使用方法 ↗

    也可以下载本机检查脚本，先查看源码，再用 Python 运行。默认只读检查，不要求安装额外 Python 库。

    python3 check.py --run-location local_mac

    在这里阅读本机报告

    选择工具导出的 JSON，最多 1 MiB。文件只在此浏览器解析，不会上传。导入记录反映生成时的机器状态。

    把「未验证」留在结果里。

    公网 IP、代理开关或一次成功连接，都不能证明所有流量始终走同一条路径。DNS、断网阻断、真实故障演练与账号状态，需要各自独立的证据。
