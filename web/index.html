    02本机体检

    下一步，检查这栋「房子」。

    浏览器只能看到小请求走过的一段路。本机工具进一步检查安装、CLI 登录、启动环境、代理与路由。

    Agent Skill

    让有本地终端权限的 Agent 来核对。

    将开源项目中的 Skill 交给 Agent，先运行只读检查。网络探测需要单独启用。云端 Agent 检查的是它所在的机器。

    查看安装与使用方法 ↗

    也可以下载本机检查脚本，先查看源码，再用 Python 运行。默认只读，不要求安装额外 Python 库。

    本机只读检查
    python3 check.py --run-location local_mac

    把本机报告带到这里。

    选择工具导出的 JSON，我们帮您读懂其中的证据。

    最多 1 MiB，只在此浏览器解析，不上传。导入记录反映报告生成时的机器状态。

    Evidence, not a promise.

    把「未验证」，
    认真留在结果里。

    公网 IP、代理开关或一次成功连接，都不能证明所有流量始终走同一条路径。DNS、故障阻断与账号状态，需要各自独立的证据。
